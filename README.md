# BirdGram for Android

BirdGram is a simple bird-observation app for recording sightings, identifying birds manually, building a Life List, and sharing selected observations with the community.

This is the **official public download repository** for the BirdGram Android application. BirdGram's private development source code is not hosted here.

## Install on Android

1. Tap **Download BirdGram APK directly** above.
2. Confirm the download in your browser.
3. Open the downloaded APK on your Android device.
4. If Android asks for permission, allow your browser or file manager to install this app.
5. Confirm installation, then open BirdGram.

Android may display a warning because the APK is installed directly rather than through Google Play. Only continue when the download address begins with:

`https://github.com/zbirdix/BirdGramApp/`
